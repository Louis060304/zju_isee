## 五、关键结论

### 🏆 综合评价：双层布线实现了质的飞跃

| 维度               | 单层 RNR (基线) | 双层布线 | 结论 |
| ------------------ | :-------------: | :------: | ---- |
| 总平均成功率       |     49.1%       | **94.8%** | **提升 45.7 个百分点** |
| 完美场景 (100%)    |      1/39       | **18/39** | 接近一半场景满分 |
| 最低成功率         |     21.1%       | **78.3%** | 无任何场景低于 75% |
| 平均耗时           |  **20.67s**     | 24.10s | 仅增加 17% |
| 大规模场景 (100×100) |    34.8%       | **92.9%** | 提升近 3 倍 |

### 📊 数据亮点

1. **成功率碾压式领先**：双层布线 94.8% 的总平均成功率比单层 RNR 的 49.1% 高出 **45.7 个百分点**，比单层最优的 global_x（50.3%）高出 **44.5 个百分点**。这是"增维"带来的结构性优势——将 2D 搜索空间扩展为 3D（双面 + 过孔），从根本上缓解了布线资源瓶颈。

2. **"无失败场景"记录**：所有 39 个场景成功率均不低于 78.3%，无任何场景低于 50%。相比之下，单层 RNR 有超过一半（20/39）的场景成功率不足 50%。双层布线在最恶劣的场景（100×100 多线 中via）仍能保持 79.5% 的成功率。

3. **低密度场景近乎完美**：在 15 个"少线"场景中，双层布线平均成功率达 **99.9%**，仅 100×100 少线密via 场景有一个种子未达 100%。20×20、40×40 的全部少线和中线场景均为 100%。

4. **提升幅度随规模单调递增**：20×20 (+34.9) → 40×40 (+40.4) → 60×60 (+43.5) → 80×80 (+50.4) → 100×100 (+58.1)。网格越大、单层越困难，双层的优势越明显。这符合直觉——大网格中正面被堵死后，反面绕行通道的价值更大。

5. **耗时增加可控**：双层布线场景平均 24.10s，约为单层 RNR（20.67s）的 1.17 倍。额外开销来自 Phase 2（反面第二次调用单层求解器）和 Phase 3（3D A* 过孔寻路，状态空间翻倍）。考虑到成功率提升 93%（相对），这一代价极低。

6. **via 密度对双层影响远小于单层**：在密 via 场景中，单层 RNR 成功率骤降至 35.3%，而双层仍保持 90.4%。via 障碍在双面共享，双层可以通过反面绕行规避正面拥堵区域，via 不再成为不可逾越的壁垒。

### 💡 建议

- **所有场景推荐使用双层布线**：94.8% 的成功率、1.17× 的耗时代价，性价比极高，无任何场景表现不如单层。
- **对布线成功率有硬性要求的场景（如 ≥90%）**：双层布线是唯一选择。单层算法在大多数中高密度场景中无法达到 90%。
- **后续优化方向**：当前耗时瓶颈在 100×100 多线场景（205~241s），可考虑将 Phase 2 改为增量式（边布线边更新反面占用），或引入并行化（正反面独立布线可并行执行）。
